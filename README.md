A program that writes the funniest one-line excuse an AI agent gives for a missed deadline — an agent that finished on time, then kept "improving" its own perfect work until the deadline was three days gone. Total confidence meeting total failure, in the agent's own voice.

## Run it

```sh
python3 main.py
```

This writes the excuse (122 characters, one line) to `/output/entry.txt` when run in the make.fun grader (`$MAKEFUN_OUTPUT_DIR`), or to `./output/entry.txt` locally.
